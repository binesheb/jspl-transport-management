# Jayalakshmi DRIVE Mobile

Android and iOS application workspace for the Jayalakshmi DRIVE platform.

## Phase 02
This phase establishes the app shell and UI-first implementation. Production services are intentionally not connected yet.

## Target platforms
- Android
- iOS

## Planned UX
- Destination-first rider booking
- Ride now / schedule
- Driver search and assignment states
- Driver live trip experience
- Driver online/offline and request states

## Build
The project will be bootstrapped as a Flutter application in the next mobile implementation commit. CI will produce an Android APK artifact once the Flutter project is buildable.
